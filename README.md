# 대한민국 인생게임

> 태어나는 것은 랜덤, 살아가는 것은 선택, 결과는 현실과 운이 결정하는 대한민국 인생 시뮬레이션.

"태어나기"를 누르면 성별을 포함한 모든 출생 조건(지역·가정 형편·부모·형제·능력·재능·성격)이 랜덤으로 정해집니다. 성별도 시드에서 뽑으므로 같은 인생 코드는 같은 성별·같은 출발점으로 태어납니다.
0세부터 죽을 때까지 한 사람의 인생이 8~10분 만에 빠르게 흘러가고, 중요한 순간마다 직접 선택합니다.
선택은 결과를 보장하지 않습니다. 능력·노력·환경·관계·과거 선택·성격·운이 합쳐져 성공 / 부분 성공 / 실패가 결정됩니다.

- 빌드 없음 · 프레임워크 없음 · 백엔드 없음 (HTML + CSS + Vanilla JS)
- 모바일 세로 화면 기준 (390×844), 360~430px 폭 대응, safe-area 지원
- LocalStorage 자동 저장 → 새로고침해도 이어하기
- Seed 기반 RNG → 같은 인생 코드 + 같은 선택 = 같은 인생 (성별 포함)
- 오늘의 인생: 날짜로 정해진 같은 출발점에서 친구와 겨루기 · 인생 도감(칭호·업적·한 줄 평·직업 수집) · 설정(속도·글자 크기·확률 근거)

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 로컬 서버로 띄우려면:

```bash
npx serve .        # 또는
python3 -m http.server 8000
```

특정 출발점으로 시작: `index.html?seed=abc123`

## 연관성 시스템 (출생 환경 · 현재 상태 · 과거 선택)

`LG.Aff`가 재능·노력·진로·전공·직업·부모 직업·지역·과거 flag에서 11개 분야(운동, 미술, 음악, 글, 과학, IT, 사업, 사람, 돌봄, 자연, 세계)의 성향 점수를 계산합니다.
- 이벤트 `dom: ['sports']` → 해당 성향이 높을수록 자주 등장
- 선택지 `rank`(숫자/함수) + 이벤트 `maxShow` → 관련 높은 선택지만 추려서 표시, `must`는 항상 표시
- 같은 분류 이벤트는 최근에 나왔으면 가중치가 떨어져 반복을 줄입니다.

## 시련 이벤트 (events-dark.js)

따돌림(피해/가담), 학교폭력, 비행, 가정 불화, 사이버 괴롭힘, 범죄 피해, 보이스피싱, 스토킹·데이트 폭력, 음주운전, 직장 내 괴롭힘, 산업재해, 도박·사채, 음주 문제, 우울 등이 환경·성격·과거 선택에 따라 확률적으로 발생합니다.
해마다 낮은 확률로 굴려야 하는 사건은 자동 이벤트에 `rate`(연 확률)를 주면 됩니다. 가해에 가담한 기억(`bully_joined`), 처분 기록(`juvenile_record`) 등은 flag로 남아 나중에 다시 돌아옵니다.
시련 이벤트에 `risk`(0~1)를 주면 자란 집(형편·불화·보호자)과 지금의 살림(자산·실직)에 따라 확률이 최대 약 2.4배↑ / 약 0.35배↓ 됩니다. `BYTIER='^d_' node tools/simulate.js 1000` 으로 형편별 발생 비율, `node tools/review.js 300` 으로 페이싱·반복 문장·자산 분포 리뷰를 볼 수 있습니다. `FREQ='^d_' node tools/simulate.js 300` 으로 이벤트별 발생 비율, `TALENT=art` 로 재능을 고정한 시뮬레이션을 볼 수 있습니다.

## 자산관리

첫 수입 이후 운용 방식(예적금/균형/성장/공격)을 정하면 남는 현금이 자동 배분되고, 매년 시장(상승·보합·하락, 코인 사이클)에 따라 손익이 납니다. 자산 시트(💰)에서 방식 변경 가능.

## 이벤트 추가하기

`data/events-*.js` 배열에 객체 하나를 `push`하면 엔진이 자동으로 인식합니다.

```js
E.push({
  id: 'w_example', cat: 'career', tier: 'choice',   // auto | choice | major
  ages: [25, 45], w: 6, cd: 5,                     // 나이 범위 · 가중치 · 쿨다운(년)
  if: p => !!p.job,                                // 발생 조건
  label: '커리어', title: '새로운 제안', text: '...',
  choices: [{
    id: 'go', label: '도전한다', intent: 'career',
    check: { base: 40, partial: 0.5, f: [['stat', 'intelligence', 0.4], ['eff', 'work', 0.3], ['flag', 'intern', 10, '인턴 경험']] },
    out: {
      success: { t: '성공 문장', log: '연표 기록', perf: 10, achv: 5 },
      partial: { t: '부분 성공 문장', perf: 3 },
      fail:    { t: '실패 문장', sr: 8, queue: [{ id: 'w_example_retry', in: 1 }] }
    }
  }]
});
```

- 확률 요인: `stat` `eff` `family` `support` `assets` `region` `talent` `trait` `flag` `noflag` `stress` `health` `happy` `edu` `ageOver` `rel` `perf` `jobYears` `job` `eduEnv` `fn`
- 결과 효과: `st` `hp` `sr` `money` `debt` `eff` `rel` `flag` `unflag` `edu` `major` `status` `job` `quit` `home` `achv` `exp` `perf` `queue` `next` `fn`
- 텍스트 토큰: `{name}` `{partner}` `{spouse}` `{friend}` `{child}` `{sibling}` `{parent}` `{job}` `{region}` — 조사 `이(가)` `와(과)` `을(를)` `(으)로`는 자동 교정

## 라이프스타일 · 선택의 무게 · 엔딩 (v3)
- **라이프스타일** (`js/style.js`, `data/events-style.js`): 성장·일·건강·가족·럭셔리·절약 + 평범. 20~24세에 처음 고르고 30/42/55/66세 점검 이벤트와 대시보드 칩에서 바꿀 수 있다(변경 후 2년 쿨다운). 각 방식은 소득·지출·건강·관계·스트레스에 해마다 작은 변화를 쌓는다.
- **선택의 무게**: 의도(`stake()`)에 따라 성공/실패 폭이 커지고, 같은 의도를 반복하면 "(익숙함)" 보정이 붙는다. 누적된 선택은 일형/가족형/도전형/안정추구형 같은 **성향 태그**가 된다.
- **엔딩**: 점수는 돈·성취·행복·관계·건강·성장으로 퍼지고 종합 등급을 낸다. 돈만으로는 높은 등급이 나오지 않는다. 칭호는 성향·라이프스타일·큰 사건을 반영한다.
- **공유 카드**: 가장 큰 갈림길 3개가 카드에 들어간다.
- **되돌릴 수 없는 선택**: 두 번 눌러 확정(메뉴 > 설정에서 끌 수 있음).
- **경제 보정**: 35세 순자산 중앙값은 가난한 집 약 0.7억 ~ 부유한 집 약 2.5억(`node tools/simulate.js`로 확인).

## 출생·자산 통계 보정 (v4)
- **출생 형편**: 5단계 + 양 극단. 극빈(기초수급 수준, 약 4%)과 재벌·자산가 가문(약 1.5%)은 `family.ext`(-1/+1)로 따로 둔다. 증여·상속·결혼 지원은 `LG.Birth.giftMul`, 부모 세대의 빚 부담은 `burdenMul`로 조절한다.
- **연령별 순자산 중앙값 목표**(통계청 가계금융복지조사 가구주 연령 기준): ~29세 0.5억 / 30대 1.56억 / 40대 2.84억 / 50대 3.74억 / 60+ 2.5억. 시뮬레이션(v5)은 23세 약 0.25억 · 29세 약 0.74억 · 35세 약 1.1억 · 45세 약 1.9억 · 55세 약 3.3억 · 65세 약 3.8억. 극빈은 23세 0.14억→65세 0.8억, 재벌가는 23세 2.8억→65세 23억 수준.
- 점검: `node tools/wealth.js 500` (연령·형편별 순자산 분위수, 23세 월수입)
- **성별은 태어날 때 랜덤**으로 정해진다 (타이틀의 "태어나기" 버튼).

## 해외로 가는 길 (`data/events-global.js`)
조기유학(12~16, 부유층) · 해외 대학원 유학 → 졸업 후 현지 취업/귀국 · 워킹홀리데이 이후 눌러앉기 · 이민 후 시민권 · 해외에서 온 부모님 입원 소식(귀국 갈림길) · 노년 영구 귀국. 해외에 사는 동안은 `p.liveIn = 'abroad'`(임금 ×1.3, 등록금 ×2.5, 주거비 해외 기준).

## 재능
- 재능은 찾기 전까지 숨겨져 있고, 이벤트로 발견되면 상태창에 나타난다 (`State.discover`가 발견 나이와 경로를 기록).
- 재능마다 **범재 · 수재 · 천재** 등급이 있다 (`p.tgrade`). 수재(재능 보유자 중 약 6%, 전체 약 5%)는 7~12세에 일찍 눈에 띄고 능력치 보정이 크다. 천재(약 0.1%)는 한 시대에 몇 명 나올까 말까 한 재능으로, 5~8세에 세상이 알아보고 보정이 가장 크다. 나머지는 범재로 스스로 찾아야 한다.
- **재능이 곧 성공은 아니다** (`data/events-talent.js`): 형편이 어려우면 레슨·장비 비용 때문에 재능을 접을 수 있고(`gt_cost`, 후원·설득으로 이어 갈 수도), 정상에 가까울수록 부상·슬럼프·기대의 무게(`gt_wall`)를 만나며, 천재는 스포트라이트의 부담(`gt_spot`)을 겪는다. 접은 재능(`p.blocked`)은 확률 보정이 30%로 줄고, 나중에 `gt_return`으로 취미·가르침의 형태로 되돌아올 수 있다.
- 엔딩 카드의 "타고난 재능"에 재능별로 일찍 두각 / 스스로 찾아냄 / 늦게 알게 됨 / 끝내 발견하지 못함이 표시된다.

## v5 — 기억이 이어지는 인생

**자동 검사** `node tools/check.js [판수]` (GitHub Actions로 push마다 실행)
1. 모든 JS 문법 · script 태그 파일 존재 2. 이벤트 id 중복 · 선택지 없는 이벤트 3. 없는 이벤트를 가리키는 queue/next
4. 기억 플래그: 설정만 되고 어디서도 안 읽히는 것 / 읽기만 하고 설정되지 않는 것 (기록용은 `LG.DATA.recordFlags`에 이유와 함께 등록)
5. index.html 중복 id 6. 무작위 N판 끝까지 진행(오류·연쇄 무한 반복·치환 안 된 문장·NaN 검사) 7. v1 저장본 → 현재 버전 변환 후 진행, 손상된 저장본 거부

**과거 선택의 메아리** (`events-echo.js`): 학창 시절의 선택이 내 아이의 학교 문제에서, 맞서 본 경험이 직장 내 괴롭힘 앞에서, 말 못 한 마음이 동창회에서, 폭락장에서 던졌던 기억이 다음 폭락장에서, 실패한 가게가 두 번째 창업에서 다시 돌아온다. 기억 플래그가 선택지를 열고 확률을 바꾼다.

**노년** (`events-elder.js`): 손주 돌봄, 사별 후 혼자 사는 삶, 배우자 간병·치매, 기억력 저하, 유언, 부고, 재개발, 노인 일자리, 늦깎이 공부, 노년의 빚 정리, 마지막 회고(가장 후회되는/오래 남은 선택). 65세 이후 선택 이벤트 빈도도 올렸다.

**사회** (`events-society.js`): 코로나 학번·코로나 자영업(해당 연도에만), '쉬었음' 청년, 부모 간병과 형제 갈등, 경력 단절과 재취업, 이혼 후 재혼, 정년 이후 재취업. 직장 내 괴롭힘·번아웃은 `events-echo.js`.

**밸런스**
- 연관 분야 이벤트 가중치 강화(연관도 40 → 약 2.5배, 70 → 약 4.5배), 같은 분류 연속 억제 강화
- 사랑·가족을 자주 고른 사람에게 인연·결혼·자녀 이야기가 더 자주 (가족 중심 플레이: 결혼 46→56%, 자녀 0.88→1.19명)
- 일 중심 전략의 과도한 우위 완화: 학력 프리미엄(경력이 쌓일수록), 기술직 상승률 조정 (순자산 9.8억 → 7억, 대신 행복·관계는 가족 중심이 크게 앞섬)
- 청혼은 같은 상대에게 최대 두 번 — "아직은 연애만"을 두 번 고르면 상대가 먼저 떠난다
- 통장이 비고 빚이 있으면 씀씀이를 벌이에 맞추고, 노년에는 파산·면책으로 빚을 정리할 수 있다 (사망 시 순자산 마이너스 23% → 약 9%)
- 군 복무 중에는 진로·창업·해외 같은 바깥 일이 일어나지 않고, 삶의 방식 선택은 전역 후로 미룬다
- 한 줄 평·성향은 '평균보다 얼마나 더 골랐나'로 판단 (한 문장이 65%를 차지하던 편중 → 최대 14%)
- 이름 뒤 조사 자동 교정("주원와" → "주원과")

**시스템**

## v9 — 연애·출산 정합성, 결혼 조건, 나이에 따른 능력치, 숫자 로그

- **연인이 생기는 순간을 분명하게**: 새 연인은 항상 "(새 연인 이름 · 나이 · 직업 · 성격)" 한 줄로 기록되고, 우연한 만남은 알림 카드로 멈춰 보여 준다. '결혼 전제 만남'이 만난 지 1년 만에 청혼으로 이어지던 문제(만난 시점을 1년 앞당기던 코드)를 없앴다.
- **결혼 조건 카드**: 청혼할 때/받을 때 상대의 나이(연상·연하), 직업, 연봉, 모은 돈, 본가 형편, 성격, 만난 기간, 신혼집 마련 가능성, 좋은 점·걸리는 점을 함께 보여 준다(`ev.facts`). 결혼하면 상대가 모은 돈과 상대 집안의 지원이 실제로 합쳐진다.
- **임신 → 이듬해 출산**: 아이는 '아이를 가질까'나 '계획에 없던 임신'에서 고른 뒤에만 생기고, 이듬해 "첫째/둘째 ○○이 태어났다" 카드로 태어난다(`k_birth`). 출산 스트레스 +5는 의도된 값(밤잠·육아)이며 카드에 이유를 적었다.
- **문구 고정**: 이벤트가 열린 순간의 제목·선택지 문구를 저장해 두고(`p.ctx.title/labels`) 결과·로그에도 그대로 쓴다 → "둘째를 갖는다"를 눌렀는데 "셋째"로 바뀌던 문제 해결.
- **나이·생활에 따른 능력치 변화**(`Life.drift`): 학습능력은 45세·60세부터, 운동능력은 30·50·65세부터 줄고, 머리 쓰는 일·운동 습관·성장형 생활이 늦춘다. 사교성은 연인·배우자·친구·직장 동료·학부모 모임으로 오르고 고립되면 준다. 정신력은 살아온 시간만큼, 창의력은 만드는 일·취미로 자란다. 성인 이후 노력치는 해마다 6%씩 옅어진다(습관이 없으면 유지되지 않는다).
- **관계 점수 계산 변경**: 평균 대신 '좋은 관계는 쌓이고, 틀어진 관계만 깎는' 방식 → 새 연인·새 친구가 생기면 관계 점수가 오히려 떨어지던 문제 해결.
- **행복 표기 점검**: 좋은 결과인데 행복이 깎이던 선택지 14곳 수정(예: "참는다… 조용히 뿌듯했다"가 행복 -2였다). `tools/audit-effects.js`가 이제 판을 복제해 모든 선택지를 실제로 눌러 보고, 결과에 적히지 않은 행복·관계 하락을 찾는다.
- **돈과 기분**: 투자로 재산 대비 크게 벌면 행복↑·스트레스↓(아주 크면 정신력 +1), 크게 잃으면 반대. 큰돈·큰 성취를 스스로 이룬 선택은 정신력 +1. 사고는 경중에 따라 행복 -2/-6/-14.
- **로또 2·3·4등**: 2등(5~8천만, 카드), 3등(120~170만), 4등(5만)이 1등보다 훨씬 자주 나온다.
- **로그에 숫자**: 선택 결과·자동 사건·가족의 죽음·상속·투자 손익 줄 끝에 "(행복 +8 · 순자산 +15억)"처럼 변화량을 붙인다(피드와 인생 기록 모두). 기쁜 알림 카드는 "기쁜 일 / 계속 살아가기"로 표시.

## v10 — 대출 종류별 상환, 부동산 시장·투자, 독촉, 노년 로그

- **빚이 안 줄던 원인**: ① 예전 빚은 한 덩어리로 해마다 이자 4%가 붙고, 원금은 '쓰고 남은 현금'에서만 10%+150만씩 갚았다. ② 남는 돈은 먼저 투자로 들어가 빚 갚는 데 쓰이지 않았다. ③ 재량 지출이 필수 지출과 따로 계산돼, 벌이가 충분해도 해마다 모자란 만큼 카드론이 새로 생겼다.
- **대출 장부(`js/loans.js`)**: 주담대 · 전세자금 · 할부 · 학자금 · 사업 · 투자 부동산 담보 · 가족에게 빌린 돈 · 세입자 보증금 · 신용대출/카드론 · 대부업 · 채무조정. 종류마다 금리·만기가 있고 해마다 이자+정해진 원금을 낸다. 남는 돈은 **금리 높은 빚부터** 갚고(카드론·대부업은 투자금을 팔아서라도), 주담대는 여윳돈의 절반을 중도상환한다. `p.debt`는 언제나 장부 합계(검사 도구가 확인).
- **연체와 독촉**: 카드론·대부업은 연체되는 그해부터 독촉 선택(`m_collect`: 털어서 갚기 · 분할 상환 약속 · 채무조정 신청 · 전화 피하기)이 오고, 대부업은 연체가 없어도 해마다 상환 안내 전화가 온다. 정기 대출(주담대·할부·학자금)은 제때 내면 문제없고, 2년 넘게 밀리면 연체 채권으로 넘어가 독촉이 시작된다. 3년 연체 또는 감당 못 할 빚은 채무조정(원금 일부 감면, 8년 분할)으로.
- **생활비 구조**: 꼭 나가는 돈(세금·생활비·주거·자녀·의료·차·보험)을 먼저 내고, 재량 지출은 '남는 돈'에서 쓴다. 모아 둔 돈이 바닥나면 씀씀이를 벌이에 맞추고(노년은 버는 만큼만), 더 빌릴 곳이 없으면 생활고 로그가 뜬다.
- **부동산 시장**: 상승기·보합·침체가 몇 년씩 이어지고, 지역마다 오르내리는 폭이 다르다(서울·수도권은 크게, 지방은 완만·약세). 집·투자 부동산·건물 값과 집값 시세(내 집 마련 가격)가 함께 움직이고, 시세가 크게 바뀌면 로그와 행복에 반영된다.
- **부동산 투자**: 투자 방식에 리츠(부동산 펀드)와 '부동산 위주' 추가. 목돈이 모이면 오피스텔 월세 · 전세 낀 갭투자 · 리츠 갈림길(`m_buy_prop`)이 오고, 크게 오르거나 빠지면 '팔까'(`m_sell_prop`, 양도세·중개비 반영). 자산 탭에 대출 종류별 목록·이자·연체와 부동산 시세를 보여 준다.
- **내 집 마련**: 결혼했거나 34세가 넘으면 몇 년에 한 번씩 꼭 찾아오는 갈림길로. 대출 한도(DSR 근사)를 넘으면 그만큼 작은 집을 산다. 40대 자가 보유율 약 50~60%.
- **80대 이후 로그 공백**: 노년 일상 문장이 23개뿐이라 몇 해 만에 바닥나 빈 해가 생겼다(의도 아님). 노년 문장 40여 개 추가(`data/flavor-elder.js`), 문장이 바닥나면 최근 것만 피해 다시 쓰도록 수정 → 80세 이후 빈 해 0%.
- 순자산 중앙값(시뮬레이션): 29세 0.4억 · 35세 0.8억 · 45세 2.5억 · 55세 4.7억 · 65세 5.4억.

## v11 — 선택 중 능력치 표시, 비율 투자, 연체 전 도움, 돈·수명 점검

- **선택지가 떠도 능력치가 보인다**: 순자산·월수입 아래에 9개 능력치 막대를 작게 계속 보여 주고, 공간이 모자라면 현황 패널 안에서 스크롤.
- **비율로 굴리기**: 자산 탭에서 예적금·주식·코인·리츠를 0~100%로 직접 정한다(합이 100% 미만이면 나머지는 현금). 예비자금을 뺀 '굴릴 수 있는 돈' 기준이며, 해마다 남는 현금으로 목표 비율까지 채운다(팔지 않고 사기만). 기존 방식들은 '빠르게 고르기'로 남김. 직접 정한 비율은 '직접 정한 비율'로 기록.
- **연체 전에 도움을 구한다(`m_loan_help`)**: 주담대·할부·학자금 등 정기 대출이 처음 밀리면, 1년 뒤 연체 채권으로 넘어가기 전에 가족 도움(관계·부모님 지원 여력) · 친구에게 빌리기(사교·우정) · 상환 유예(학자금은 성공률 높음) · 허리띠 졸라매기 중 고른다.
- **학자금 = 취업 후 상환**: 학생·군인·아르바이트이거나 연 소득 2,500만 원 미만이면 원금 상환이 미뤄지고 연체가 생기지 않는다. 대학생 생활비 부족분은 카드론이 아니라 학자금(생활비) 대출로.
- **월수입 표시**: 배우자 소득이 있으면 '월 수입 (부부 합산)'으로 표시하고, 자산 탭에 내 월급·배우자 월급·임대 수입을 나눠 보여 준다.
- **돈 계산 점검**: 이벤트의 '돈이 있나?'·금액 계산이 통장 현금만 보던 곳 27군데를 '현금+투자 자산' 기준으로 수정(자녀 증여 0원, 기부·사기 피해·지원금이 0에 가깝던 문제). 재개발 분담금은 모은 돈→투자 자산→대출 순으로 마련하고 정말 모자랄 때만 입주권을 판다. 이혼 시 투자 자산·투자 부동산도 나눈다. 재량 지출을 정할 때 올해 갚을 대출 원리금을 먼저 떼어 둬 상환일 연체가 줄었다. 자산이 많을수록 씀씀이가 커지고 은퇴 뒤엔 조금씩 헐어 쓴다(90대에 수십억이 불어나던 문제). 65세 넘은 구직자는 은퇴로, 60세 넘어 빚에 쫓기면 주택연금.
- **수명**: 60대 후반부터 건강이 해마다 더 크게 꺾이고(관리하면 늦춤), 나이가 많을수록 낮은 건강이 사망 위험을 더 키운다. 급사(갑작스러운 심근경색·뇌졸중)는 약 1/4로 줄였다. 시뮬레이션 평균 수명 남 약 79세 · 여 약 84세, 90세 이상 남 약 12% · 여 약 32%, 100세 이상 1~2%(전엔 여성 24%가 100세를 넘겼다).
